# Data

**Source:** Amazon Reviews'23 — McAuley Lab, UC San Diego
Official page: https://amazon-reviews-2023.github.io/

Raw and processed data are **not** committed to GitHub (see `.gitignore`).
Everything here must be rebuildable from the scripts in `src/`.

## Files (per category)
| File | Content | Download date |
|---|---|---|
| `raw/<Category>.jsonl` | User reviews | _to fill (task 3)_ |
| `raw/meta_<Category>.jsonl` | Product metadata | _to fill (task 3)_ |

## Subset rules
_To fill in tasks 3 and 10, and locked before modeling._
